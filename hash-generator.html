About cryptographic hashes

A hash function turns any input into a fixed-size fingerprint. The same input always produces the same hash, a tiny change produces a completely different one, and the original cannot be recovered from the hash. Hashes verify downloads, detect tampering, deduplicate data and, with a key (HMAC), authenticate messages.

Frequently asked questions

SHA-256 is the safe default for integrity checks and signatures. MD5 and SHA-1 are broken for security but still fine for checksums and cache keys. For passwords use bcrypt, scrypt or Argon2 instead of any plain hash.
