How to use

  1. Paste or upload Markdown on the left.
  2. Read the structured JSON on the right, or switch to Preview to see the rendered HTML.
  3. Copy or download the JSON, HTML or original Markdown, or print the preview to PDF.

Structured Markdown

The converter parses Markdown into a block tree: every heading, paragraph, list, table, code block and quote becomes a JSON object with its own type and content. The structure is ideal for search indexing, migrating content into a CMS or generating navigation from headings.

Frequently asked questions

A document object with the title (first heading), an array of blocks (headings with level, paragraphs, code blocks with language, ordered and unordered lists, tables with headers and rows, blockquotes, horizontal rules) and word, heading, link and code block counts.
