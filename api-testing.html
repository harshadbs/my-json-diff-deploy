About the API client

This free online REST client sends GET, POST, PUT, PATCH, DELETE, OPTIONS and HEAD requests straight from your browser. Add query parameters, headers, a JSON, XML, form or raw text body, and bearer, basic, API-key or JWT authentication. The response panel shows the status, timing, size and headers, renders JSON as a collapsible tree or pretty-printed code, and can diff two responses to see what changed between calls.

Requests, collections, environments, history and favorites are stored in your browser only. Nothing is proxied through a server, which also means the API you call must allow cross-origin (CORS) requests from the browser, as public APIs and most development servers do. For internal APIs that do not send CORS headers, enable them on the server or use the client from the same origin.

Typical uses

  • Trying a public API or a webhook before writing code
  • Checking a deployment by replaying a saved collection of requests
  • Comparing the JSON returned by two environments with the built-in response diff
  • Debugging authentication by inspecting the exact headers sent and received
